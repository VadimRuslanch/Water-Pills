# План 1. Из каких частей состоит приложение

Рабочее название условно `Water & Pills`.

## 1. Экран «Сегодня»

Это главный экран приложения. Пользователь открывает PWA и сразу видит, что ему нужно сделать сегодня.

### Вода

Показываем:

* дневную цель, например `2500 мл`;
* сколько уже выпито;
* сколько осталось;
* progress bar;
* процент выполнения;
* быстрые кнопки:

    * `+250 мл`;
    * `+500 мл`;
* кнопка добавления своего количества;
* возможность отменить последнее добавление.

Пример:

```text
Вода

1750 / 2500 мл
██████████████░░░░

Осталось 750 мл

[ +250 мл ] [ +500 мл ]
[ Другое количество ]
```

---

### Таблетки на сегодня

Показываем только препараты, которые должны быть приняты сегодня.

Карточка:

```text
09:00

Витамин D
1 таблетка

[ Принял ]
[ Отложить ]
```

После приема:

```text
✓ Принято в 09:07
```

Статусы:

```ts
pending
taken
skipped
snoozed
```

Если таблеток несколько:

```text
Сегодня

✓ 09:00 Витамин D
○ 14:00 Магний
○ 21:00 Омега-3
```

## 2. Раздел «Вода»

Более подробная информация по воде.

### Что здесь будет

Текущая цель:

```text
2500 мл / день
```

История сегодняшнего дня:

```text
08:20 — 250 мл
10:10 — 500 мл
12:40 — 250 мл
```

Действия:

```text
+250 мл
+500 мл
Добавить вручную
```

Позже:

* график за неделю;
* среднее потребление;
* количество выполненных дней;
* streak.

Дата окончания

Приложение должно:

* устанавливаться на телефон;
* иметь иконку;
* запускаться standalone;
* работать после перезагрузки;
* хранить данные локально;
* частично работать offline;
* использовать notification API;
* использовать service worker.

# Глобальное состояние

Для проекта я бы взял:

```text
Zustand
```

Не Redux Toolkit — здесь он скорее избыточен.

Глобально хранить:

```ts
type AppStore = {
  waterGoal: number;
  waterEntries: WaterEntry[];

  medications: Medication[];
  medicationIntakes: MedicationIntake[];

  settings: Settings;
};
```

Например:

```ts
type WaterEntry = {
  id: string;
  amount: number;
  createdAt: string;
};
```

```ts
type Medication = {
  id: string;
  name: string;
  dosage: string;
  times: string[];
  daysOfWeek: number[];
  startDate: string;
  endDate?: string;
};
```

```ts
type MedicationIntake = {
  id: string;
  medicationId: string;
  scheduledAt: string;
  takenAt?: string;
  status: "pending" | "taken" | "skipped";
};
```

# Что НЕ нужно класть в глобальный state

Например состояние формы:

```ts
const [name, setName] = useState("");
```

не нужно хранить в Zustand.

Для форм:

```text
React Hook Form
+
Zod
```

В глобальный store идет только то, что реально используется в разных частях приложения.

# Хранение данных

Для первой версии:

```text
Zustand
   ↓
IndexedDB
```

Я бы использовал:

```text
Dexie.js
```

А не `localStorage`.

Потому что потом появятся:

* сотни записей воды;
* история приемов;
* статистика;
* даты;
* разные препараты.

Для такого IndexedDB подходит лучше.
