# Запуск проекта

## Требования

- Node.js 20.19 или новее;
- npm 10 или новее.

## Первый запуск

```bash
npm install
npm run dev
```

После запуска Vite выведет локальный адрес приложения в терминале.

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
```

`npm run preview` запускает локальный просмотр production-сборки.

## Границы стартового каркаса

В init входят окружение, маршрутизация, пустые страницы и нижняя навигация.
Функциональность воды, препаратов, форм, хранилища и уведомлений реализуется
самостоятельно по этапам из `dock/Release.md`.
